# Piano

## 專案介紹
本程式使用 Win API 的 Beep() 函式製作簡易電子琴，  
按下按鈕即可播放不同音階。

---

## 功能介紹
- 播放 Do Re Mi Fa Sol La Si Do
- 共用按鈕事件
- 視窗縮放時自動調整按鈕大小

---

## 使用技術
- C#
- Windows Forms
- Win API
- Beep()

---
